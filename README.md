# TUMAN

«Белое море — Ночная вахта»: атмосферный игровой прототип с видом сверху.

[Скачать Windows x64 — v0.2.0](https://github.com/ashenwish/TUMAN/releases/download/v0.2.0/WhiteSea-Windows-x64-v0.2.0.zip) · [Описание релиза](https://github.com/ashenwish/TUMAN/releases/tag/v0.2.0)

Распакуй ZIP и запусти `WhiteSea.exe`. Устанавливать Godot не нужно; ресурсы встроены в EXE. В архив включены инструкция и лицензии.

- WASD/стрелки — ходьба, мышь — взгляд.
- Shift — бег, F — достать/убрать лампу.
- Удержание ПКМ — поднять лампу и дальше рассеивать туман; отпускание — опустить.
- R — вернуться на берег, F11 — полный экран, Esc — в окно.

В v0.2.0 обновлены модель и анимации смотрителя, лампа, туман, экстерьер маяка и материалы окружения. Земля и берег используют уникальную карту без заметной тайловой сетки.

Сборка: Godot 4.7.2, Windows x64, GL Compatibility. [SHA-256](https://github.com/ashenwish/TUMAN/releases/download/v0.2.0/SHA256SUMS.txt). Предыдущие сборки и архив проекта доступны в [Releases](https://github.com/ashenwish/TUMAN/releases).
